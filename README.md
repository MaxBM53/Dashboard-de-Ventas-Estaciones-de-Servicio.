# ⛽ Dashboard de Ventas y Estimación de Ganancias - EESS Argentina

Un dashboard interactivo desarrollado en **Python** utilizando **Streamlit** y **Plotly** para el análisis dinámico del volumen de ventas de combustibles, facturación bruta y estimación de márgenes de ganancia en Estaciones de Servicio (EESS) de Argentina.

---

## 🚀 Características Principales

- **Filtros Interactivos:** Selección en tiempo real por Provincia y Bandera/Operador (YPF, Shell, Axion, etc.).
- **Indicadores Clave de Negocio (KPIs):**
  - Volumen Total Vendido (Litros / $m^3$).
  - Facturación Total Estimada (ARS).
  - Ganancia Bruta Estimada (Basada en comisiones promedio de surtidor).
  - Ticket Promedio por Operación.
- **Visualización de Datos:**
  - Gráfico de barras comparativo de volumen vendido por bandera comercial.
  - Gráfico de dona (Pie Chart) interactivo con la distribución de ingresos por tipo de producto (Nafta Super, Premium, Diesel, GNC).
- **Exploración de Datos:** Tabla interactiva expandible para inspeccionar y filtrar el DataFrame procesado.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python 3.11+
- **Framework Web:** [Streamlit](https://streamlit.io/)
- **Manipulación de Datos:** Pandas, NumPy
- **Visualización:** Plotly Express
